# Agent Directory Submissions

Complete, working sample submissions for the directories where AI assistants find products: copy one, change the fields, submit.

Every sample comes from a real, live MCP server, [API Lessons](https://www.level250.com/mcp/lessons/docs/v1) (`https://lessons.mcp.level250.com/mcp`), so the values are real, not placeholders. Each folder has a README that walks through the submission from start to finish.

| Directory | Folder | What you submit |
|---|---|---|
| ChatGPT plugins (OpenAI) | [`chatgpt/`](chatgpt/) | A ZIP: `plugin.json` + `mcp.json` + icons |

More directories (Claude, Gemini, Muse) will be added here.

## How to use a sample

1. **Get the files.** On this page, select **Code → Download ZIP** and unzip it, or run `git clone https://github.com/paraskakis/agent-directory-submissions.git`. That download is the whole repo, not a plugin: don't upload it.
2. **Copy the sample folder** (for ChatGPT: `chatgpt/api-lessons/`) to where you keep your work, and rename it after your product.
3. **Edit your copy:** open each file in your editor and change the fields one by one, following that directory's README.
4. **Package and submit** as that README shows.

The samples follow each directory's documentation as of the date in its README. Directories change their rules often, so check the linked docs before you submit.
